# Tools and code

## Mathematical model of RBC dynamics including the spleen

We have created a mathematical model of red blood cell (RBC) dynamics in a malaria infection, which is unique in including the spleen as a separate model compartment that can retain large amounts of infected and uninfected RBCs.
This model is freely available as an R package with online documentation:

[The `spleenrbc` R package](https://rgmoss.pages.gitlab.unimelb.edu.au/malaria-spleen-rbc-loss/){ .md-button .md-button--primary }

- {{ cite("10.1371/journal.pcbi.1013865") }}

## Automatic reporting of primaquine dose efficacy, tolerability, and safety

National malaria control programs have requested local data to better understand the effect of primaquine dose for their local context.
This led to the development of automated reports that provide an overview of primaquine dose efficacy, tolerability, and safety for *Plasmodium vivax* malaria, based on a database of individual patient data from antimalarial efficacy studies.

[Automated vivax reports](https://www.iddo.org/wwarn/vivax-reports){ .md-button .md-button--primary }

- {{ cite("10.1186/s12936-025-05642-w") }}
